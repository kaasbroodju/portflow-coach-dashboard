## Installeren of bijwerken

Je hebt **Google Chrome** nodig; Python of andere programma's hoef je niet zelf te installeren. Heb je het dashboard al, dan werk je het bij met **Nu bijwerken** in het dashboard, of met dezelfde regel als hieronder.

**macOS:** open *Terminal* (⌘-spatie, typ "Terminal"), plak deze regel en druk op Enter:

```
curl -fsSL https://github.com/petersnoek-hu/portflow-coach-dashboard/releases/latest/download/install-macos.sh | sh
```

**Windows:** open *PowerShell* (Startmenu, typ "PowerShell"), plak deze regel en druk op Enter:

```
irm https://github.com/petersnoek-hu/portflow-coach-dashboard/releases/latest/download/install-windows.ps1 | iex
```

Daarna open je het dashboard met de snelkoppeling: op macOS **Portflow coach dashboard** in de map Apps in je thuismap, op Windows in het Startmenu en op het bureaublad. Meer uitleg, ook over verwijderen, staat in de [README](https://github.com/petersnoek-hu/portflow-coach-dashboard#installeren).
